Crypto Quant Wizard의 시스템 아키텍처, 3대 퀀트 전략 및 5.2년 백테스트 검증 결과, 거래소 API Key 발급부터 24시간 오라클 클라우드 무인 배포까지 완벽하게 안내합니다.

1. 3분 로컬 퀵스타트 & 런처 안내

Zero Build Friction

별도의 복잡한 Node.js 빌드 과정 없이, Python 3.10+ 환경에서 원클릭 런처 스크립트만 실행하면 가상환경 구축, 필수 패키지 설치, 로컬 웹 서버 및 백그라운드 스케줄러가 한 번에 자동 기동됩니다.

운영체제별 원클릭 실행 방법

  • Windows 사용자: 프로젝트 폴더 내 start.bat 파일을 더블 클릭합니다.
    가상환경(`.venv`) 확인, 필수 라이브러리 자동 설치, 웹 서버 기동 후 기본 브라우저(`http://localhost:8080`)가 자동으로 열립니다.
  • Linux / macOS / Cloud VM 사용자: 터미널에서 권한 부여 후 실행합니다.
    chmod +x start.sh && ./start.sh
  • Docker 컨테이너 환경: Docker Compose를 통해 1줄로 격리 실행할 수 있습니다.
    docker compose up -d
[데이터 및 설정 보관 원칙]
• 본 플랫폼은 100% 로컬 구동 오픈소스 소프트웨어입니다. 입력하신 거래소 API Key 및 트레이딩 전략 설정은 여러분의 컴퓨터 내 .env 파일에만 저장되며, 외부 어떤 서버로도 전송되지 않습니다.

왜 백테스트 MDD(최대 낙폭)가 중요한가요?

코인 시장에서 단순 보유(존버) 전략은 상승장에서는 돈을 벌지만, 하락장에서 -70%에서 -80% 수준의 폭락을 그대로 얻어맞아 계좌가 회복 불능 상태에 빠집니다. 본 봇의 전략들은 하락 추세 감지 시 원화(KRW) 또는 테더(USDT)로 전량 대피하여 계좌의 최대 낙폭을 -20%대로 철저히 묶어두고, 다시 안전한 상승 파동이 확인될 때만 재진입하여 복리 수익을 극대화합니다.

3. 거래소 API Key 및 디스코드 웹훅 발급 매뉴얼

Security & Integration
[최우선 필수 보안 수칙] (모든 거래소 공통)
• 어떤 경우에도 출금(Withdraw) 권한은 절대 체크하지 마세요! 봇은 '자산 조회'와 '주문(매수/매도)' 권한만 있으면 100% 정상 작동합니다. 출금 권한을 주지 않으면 설령 키가 유출되더라도 외부로 자산이 빠져나갈 위험이 없습니다.
• 발급받은 Secret Key는 창을 닫으면 두 번 다시 확인할 수 없으므로, 발급 직후 복사하여 마법사에 붙여넣으세요.

업비트 (Upbit) API Key 발급

  1. 업비트 웹사이트 로그인 → 우측 상단 [마이페이지] → 좌측 [Open API 관리] 메뉴로 이동합니다.
  2. Open API 주요 기능 중 [자산조회], [주문조회], [주문하기] 3개만 체크합니다. (출금 관련 항목 절대 체크 금지)
  3. 특정 IP 등록: 오라클 클라우드 고정 공인 IP 또는 로컬 PC IP를 입력합니다. (미등록 시 업비트 정책상 API 호출이 차단됩니다.)
  4. 2채널 인증(카카오페이 / 네이버인증) 완료 후 발급된 Access Key와 Secret Key를 복사하여 마법사에 입력합니다.

빗썸 (Bithumb) API Key 발급

  1. 빗썸 로그인 → 우측 상단 [고객센터] → [API 관리] 메뉴로 이동합니다.
  2. 권한 선택에서 [회원정보 및 거래내역 조회], [주문(매수/매도)]만 활성화합니다. (출금 관련 비활성화 유지)
  3. IP 주소 제한: 서버 또는 PC의 공인 IP를 등록합니다.
  4. SMS 또는 OTP 인증 후 생성된 키 쌍을 복사하여 마법사에 입력합니다.

바이낸스 (Binance) API Key 발급

  1. 바이낸스 로그인 → 우측 상단 프로필 → [API Management] → [Create API] 클릭합니다.
  2. API 유형으로 [System generated]를 선택하고 식별용 라벨(예: crypto-quant-wizard)을 입력합니다.
  3. API 권한에서 [Enable Reading] 및 [Enable Spot & Margin Trading] 2개만 체크합니다.
  4. IP Access Restriction: [Restrict access to trusted IPs only] 선택 후 서버 고정 IP를 등록합니다.
  5. 발급된 API Key와 Secret Key를 마법사에 입력합니다.

디스코드 (Discord) 스마트폰 알림 웹훅 발급

  1. 디스코드 PC 프로그램 또는 웹에서 알림을 수신할 본인만의 개인 서버를 하나 생성합니다. (무료)
  2. 알림을 받을 채널(예: #트레이딩-리포트) 우측의 톱니바퀴 [채널 설정] 클릭 → 좌측 [연동] 메뉴로 이동합니다.
  3. [웹후크(Webhook)] 클릭 → [새 웹후크 만들기] 클릭 후 [웹후크 URL 복사] 버튼을 누릅니다.
  4. 복사한 주소(https://discord.com/api/webhooks/...)를 설정 마법사에 붙여넣고 [테스트 발송]을 눌러 스마트폰으로 알림이 오는지 확인합니다.

4. 오라클 클라우드(OCI) Always Free 24시간 무인 배포 가이드

365 Days Unattended
[내 컴퓨터를 24시간 켜둘 필요가 없습니다!]
오라클 클라우드의 평생 무료 가상 컴퓨터(Always Free VM)에 본 봇을 올려두시면, 집 PC를 완전히 끄고 외출하거나 자는 동안에도 매일 아침 09:05 KST에 자동으로 시장을 분석하고 매매한 뒤 스마트폰 디스코드로 리포트를 보내줍니다.

6단계 완벽 배포 가이드

  1. 1단계: 오라클 클라우드 회원가입 및 평생 무료 인스턴스 생성
    • cloud.oracle.com 에서 무료 계정 가입 후 콘솔로 로그인합니다.
    • OCI 콘솔 좌측 메뉴 → [컴퓨트] → [인스턴스] → [인스턴스 생성] 클릭
    • 모델(Shape): 반드시 `VM.Standard.E2.1.Micro` (AMD) 선택 (Always Free 평생 무료 마크 확인)
    • 이미지(OS): Ubuntu 24.04 LTS 또는 22.04 LTS 선택
    • SSH 키: [자동으로 키 쌍 생성] → [프라이빗 키 다운로드] 클릭 후 .key 파일을 PC에 보관
  2. 2단계: 영구 고정 공인 IP(예약된 공용 IP) 할당 (필수)
    • 인스턴스 상세 화면 → [네트워킹] → 기본 VNIC 클릭 → [IP 관리] 클릭
    • 프라이빗 IP 행 우측 점 3개(...) → [편집] → `예약된 퍼블릭 IP` 선택 후 새 예약 IP 발급
    • 효과: 서버를 재부팅해도 IP가 절대 변경되지 않아 업비트/빗썸/바이낸스 화이트리스트에 평생 등록 가능합니다.
  3. 3단계: 웹 대시보드 접속을 위한 8080 방화벽 포트 개방
    • OCI 콘솔 → [가상 클라우드 네트워크(VCN)] → 보안 목록(Security Lists) → `Default Security List` 클릭
    • [수신 규칙 추가(Add Ingress Rules)] 클릭:
    • 소스 CIDR: 0.0.0.0/0, 대상 포트: 8080, 프로토콜: TCP, 설명: Web UI
  4. 4단계: 거래소 API 관리에 발급받은 서버 고정 IP 등록
    • 업비트, 빗썸, 바이낸스의 API 설정 메뉴에서 위 2단계에서 발급받은 <오라클_고정_공인_IP>를 화이트리스트에 등록합니다.
  5. 5단계: 서버 접속 및 원클릭 런처 구동 (터미널 명령어)
    PC 터미널에서 SSH 키로 서버에 접속한 후 아래 명령어를 입력합니다:
    ssh -i <키파일경로.key> ubuntu@<오라클_고정_IP>
    시스템 패키지 설치 및 리포지토리 클론:
    sudo apt update && sudo apt install -y python3 python3-venv git git clone https://github.com/haksoo0918/crypto-quant-wizard.git cd crypto-quant-wizard && chmod +x start.sh
  6. 6단계: 백그라운드 24시간 365일 무중단 가동 명령어
    터미널 창을 닫아도 백그라운드에서 계속 실행되도록 nohup 명령으로 기동합니다:
    nohup ./start.sh > server.log 2>&1 &
    이제 스마트폰이나 PC 브라우저 주소창에 `http://<오라클_고정_IP>:8080` 을 입력하면 언제 어디서든 대시보드와 설정 마법사에 접속할 수 있습니다!

5. 봇 상시 운용, 스케줄 관리 및 안전 종료 방법

Process Control

일체형 스케줄러 (매일 아침 09:05 KST) 동작 원리

start.bat 또는 start.sh를 실행하면 웹 서버 프로세스 내에 자동 스케줄러(APScheduler)가 함께 탑재되어 백그라운드에서 동작합니다. 매일 아침 09:05 KST(일봉 확정 직후)가 되면 자동으로 3대 거래소의 시장 데이터를 수집하여 지표를 산출하고, 진입/청산 조건 충족 시 주문을 실행한 뒤 체결 장부 갱신 및 디스코드 리포트를 전송합니다.

스케줄 일시정지 및 끄기 (웹 화면 1초 제어)

자동 매매를 잠시 쉬고 싶거나 수동 실행 모드로만 운용하고 싶을 때는, 대시보드 상단 배너의 `[매일 09:05 KST 자동실행]` 버튼을 클릭하거나 설정 마법사의 `[스케줄 자동 실행 활성화]` 체크를 해제하시면 즉시 정기 스케줄이 중단됩니다.

Windows 작업 스케줄러 원클릭 자동 실행 및 삭제 도구

  • 부팅 시 자동 실행 등록: 프로젝트 내 scripts/register_windows_task.bat 을 더블 클릭하면, Windows 로그인 시 자동으로 봇이 백그라운드 구동되도록 작업 스케줄러에 등록됩니다.
  • 스케줄 완전 삭제: scripts/unregister_windows_task.bat 을 더블 클릭하면 등록된 윈도우 스케줄이 1초 만에 깔끔하게 삭제됩니다.

실행 중인 터미널 안전 종료 방법

로컬 PC에서 봇을 종료하고자 할 때는, 실행 중인 검은색 터미널 콘솔 창을 활성화한 후 키보드의 `Ctrl + C` 를 누르고 y를 입력하거나, 창 우측 상단의 `X` (닫기) 버튼을 클릭하시면 프로세스가 안전하게 종료됩니다.

6. 자주 묻는 질문 (FAQ) & 트러블슈팅

Troubleshooting
Q. API [연결 테스트] 시 연결 실패 오류가 발생합니다.
1. IP 화이트리스트 불일치: 거래소 API 설정에 등록한 IP와 현재 컴퓨터(또는 서버)의 공인 IP가 일치하는지 확인하세요.
2. 키 복사 오류: 키 앞뒤에 공백(스페이스)이 들어가지 않았는지 확인하세요.
3. 권한 누락: '자산조회' 및 '주문' 권한이 정상 부여되었는지 확인하세요.
Q. 컴퓨터를 끄면 봇이 동작하지 않나요?
로컬 PC에서 실행 중인 경우 컴퓨터 전원이 꺼지면 프로세스도 종료되므로 다음 날 09:05 스케줄이 실행되지 않습니다. 24시간 365일 무인 가동을 원하실 경우 위 [4. 오라클 클라우드 24시간 무인 배포 가이드]를 따라 평생 무료 VM에 올려두시는 것을 적극 권장합니다.
Q. 3개 거래소(업비트/빗썸/바이낸스)를 모두 등록해야 하나요?
아닙니다. 본인이 현재 사용하시는 거래소 1곳의 API Key만 입력하셔도 완벽하게 단독 운용됩니다. 사용하지 않는 거래소는 키를 비워두시고 전략 매핑을 '사용 안 함'으로 설정하시면 됩니다.
Q. 모의투자(Dry-Run)와 실거래(Live Trading)의 차이는 무엇인가요?
모의투자는 실제 거래소로 주문을 넣지 않고, 가상 잔고 1,000만원을 기준으로 시장 체결가와 수수료(0.05%), 슬리피지(0.1%)를 반영하여 시뮬레이션 매매를 수행합니다. 실거래 전환 전 전략의 정확한 동작을 확인하는 데 가장 안전합니다.
