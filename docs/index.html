🧙 퀀트 봇 설정 마법사

누구나 쉽게 시작하는 3대 거래소 암호화폐 퀀트 플랫폼입니다. 아래 4단계를 따라 설정을 완료해 보세요.

💡 [처음 시작하시는 분들을 위한 친절 가이드]
• 모의투자 우선 권장: 처음이시라면 [1. 운용 모드]에서 🟢 모의투자 (Dry-Run)를 선택하세요. 실제 돈이 나가지 않고 가상 잔고로 전략의 정확한 동작을 먼저 확인할 수 있어 안전합니다.
• 선택적 거래소 등록: 3개 거래소를 모두 등록할 필요가 없습니다. 현재 사용하시는 거래소 1곳만 키를 입력하셔도 정상 가동됩니다.
• 철저한 개인정보 보호: 입력하신 API Key는 여러분의 PC(로컬 파일)에만 안전하게 보관되며, 그 어떤 외부 서버로도 전송되지 않습니다.

3. 거래소별 퀀트 전략 매핑 및 특징

각 거래소의 시장 특성(원화 마켓 vs 글로벌 테더 마켓, 단독 코인 집중 vs 분할 리밸런싱)에 맞추어 설계된 검증된 모델들입니다.

📈 [BTC/ETH 50:50 동적 리밸런싱 전략의 특징]
• 분할 리스크 관리: 총 평가액을 비트코인 50%, 이더리움 50%로 나누어 배분합니다.
• 이중 추세 필터: BTC는 220일 이동평균선(±2% 버퍼), ETH는 50일 이동평균선(1.5 ATR 채널)을 돌파하는 강력한 상승장일 때만 진입합니다.
• 수익 보존 리밸런싱: 한쪽 코인이 급등하여 자산 비중이 60%를 초과하면 초과분을 즉시 시장가 매도하여 원화(KRW) 50%를 확보, 수익을 확정합니다.
🚀 [이더리움 SuperTrend 추세추종 전략의 특징]
• 100% 집중 공격형: 높은 변동성을 가진 이더리움(ETH) 1종목에 자산 100%를 집중 운용합니다.
• 복합 지표 필터: 50일 SMA 대추세선 위에 있고 SuperTrend(7, 3.5)가 상승 밴드(Green)일 때 100% 풀매수 보유합니다.
• 철저한 하락장 회피: 하락 시그널 발생 즉시 100% 원화로 전량 현금화하여 최대 낙폭(MDD -25% 수준)을 완벽히 방어합니다.
💵 [BTC/ETH 글로벌 테더(USDT) 리밸런싱 전략의 특징]
• 김치프리미엄 배제: 순수 글로벌 달러 테더(USDT) 마켓에서 달러 자산을 안정적으로 증식합니다.
• 글로벌 최적 파라미터: 5.2년 실데이터 검증 최적치(BTC 200일 SMA, ETH 40일 SMA 1.2 ATR) 채널을 적용합니다.
• 환율 리스크 분산: 관망 시 안전한 달러(USDT)를 보유하여 원화 약세/환율 급등 리스크를 자연스럽게 헤지합니다.
4. 디스코드(Discord) 모바일 알림 설정 (선택 사항) 🔔 웹훅 URL 발급 방법
• 어떤 기능인가요?: 매일 아침 09:05 KST 정기 매매가 완료되면, 당일 주문 체결 내역과 3대 거래소별 자산 잔고, 종합 수익률 리포트를 본인의 스마트폰 디스코드 앱으로 자동 푸시 전송해 줍니다.
• 왜 쓰나요?: 매번 컴퓨터나 오라클 클라우드에 로그인하지 않아도, 아침 출근길이나 외출 중에 스마트폰 알림으로 매매 결과를 즉시 확인할 수 있습니다.
• 선택 사항: 디스코드 알림을 받지 않으려면 빈칸으로 비워두셔도 자동 매매와 웹 대시보드는 100% 정상 작동합니다.
디스코드 채널 설정에서 복사한 웹후크 주소를 붙여넣고 [테스트 발송]을 눌러보세요.
5. 정기 자동 매매 스케줄링 설정
• 활성화(체크): 매일 아침 09:05 KST(일봉 마감 직후)에 봇이 자동으로 시장 데이터를 분석하고 매매 사이클을 실행합니다.
• 비활성화(체크 해제/삭제): 정기 스케줄이 중지되며, 상단 [⚡ 지금 1회 수동 실행] 버튼을 누를 때만 매매가 실행됩니다.
⏰ 봇 상시 운용 및 종료 안내
• 자동 스케줄 대기: [설정 저장]을 완료하시면 내장 스케줄러가 활성화되어 터미널 창을 켜두시는 동안 매일 아침 09:05 KST에 자동으로 분석 및 매매를 실행합니다. 매일 start.bat을 다시 실행하실 필요가 없습니다.
• 컴퓨터를 껐다 켰을 때: PC를 재부팅했거나 터미널을 닫았다면, 다음 날 09:05 전에 start.bat을 한 번만 다시 실행해 두시면 됩니다.
• 터미널 종료 방법: 실행 중인 검은색 터미널 창에서 Ctrl + C 를 누르고 y를 입력하시거나, 창 우측 상단의 X 버튼을 클릭하시면 안전하게 종료됩니다.
• 24시간 무인 가동: 집 PC를 매일 켜두기 번거로우실 땐 오라클 클라우드 평생 무료 VM에 올려두시면 PC를 끄고도 365일 무중단으로 자동매매가 진행됩니다.
